# University Library Management System

## 1. Project Overview

The University Library Management System (LMS) is a proposed software system designed to manage library books, student memberships, borrowing, returns, and overdue books.

## 2. Objectives

* Maintain book records.
* Manage book borrowing and returns.
* Maintain student membership records.
* Track overdue books.
* Reduce manual record-keeping.
* Improve access to library information.

## 3. Project Scope

The project includes requirements analysis, stakeholder identification, project planning, Software Requirements Specification (SRS), requirements diagrams, and a prototype.

The complete implementation of the software system is outside the current project scope.

## 4. Assumptions

* Students and library staff will use the system.
* Every book will have a unique identification number.
* Library staff will maintain accurate records.
* Users will have access to a suitable computer or device.

## 5. Constraints

* Limited time and resources.
* A team of three members.
* Limited access to actual university library data.
* The assignment focuses on software engineering analysis and design rather than full implementation.
