# Prototype Description

## Overview

The prototype will demonstrate the basic interface and functionality of the University Library Management System.

## Main Screens

### 1. Login Screen

Allows authorized users to access the system.

### 2. Dashboard

Displays a summary of books, registered students, and borrowing activities.

### 3. Book Management

Allows users to add, update, delete, and search for book records.

### 4. Student Management

Allows authorized users to manage student information.

### 5. Book Issue and Return

Allows library staff to record book borrowing and returns.

### 6. Book Search

Allows users to search for books by title, author, or category.

## Prototype Objective

The prototype will help stakeholders understand the proposed system's layout, navigation, and core features before full implementation.

## Prototype Status

Planned.
