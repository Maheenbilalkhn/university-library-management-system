
# University Library Management System

## 1. Project Overview
The University Library Management System (LMS) is a proposed software system to manage library books, borrowing, returns, student memberships, and overdue books.

## 2. Objectives
- Maintain book records.
- Manage borrowing and returning.
- Manage student memberships.
- Track overdue books.
- Reduce manual record-keeping.

## 3. Project Scope
The project covers requirements analysis, system planning, stakeholder analysis, SRS documentation, diagrams, and a prototype.

## 4. Assumptions
- Students and library staff can access the system.
- Each book has a unique identification number.
- Library staff maintain accurate book records.

## 5. Constraints
- Limited project time and resources.
- The team has three members.
- The complete system implementation is not required.
