# Risk Register

| ID | Risk                        | Probability | Impact | Mitigation Strategy                                      |
| -- | --------------------------- | ----------- | ------ | -------------------------------------------------------- |
| R1 | Project delays              | Medium      | High   | Prepare a schedule and monitor progress.                 |
| R2 | Unclear requirements        | Medium      | High   | Confirm requirements before development.                 |
| R3 | Team communication problems | Medium      | Medium | Conduct regular team meetings.                           |
| R4 | Technical difficulties      | Medium      | High   | Research solutions and test components early.            |
| R5 | Data loss                   | Low         | High   | Maintain regular backups and use GitHub version control. |

## Risk Monitoring

The team will review project risks regularly and update this register when necessary.
