# University Library Management System

## Project Overview

The University Library Management System is a software engineering project designed to organize library operations, including book management, student records, book borrowing, and book returns.

## Objectives

* Improve book record management.
* Maintain student borrowing records.
* Simplify book searching and availability checking.
* Make library operations more organized.
