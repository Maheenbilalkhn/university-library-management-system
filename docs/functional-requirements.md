Functional Requirements

1. Introduction

Functional requirements describe the operations and services that the University Library Management System must provide.

The following requirements are preliminary and must be reviewed by the project team before they are finalized.

2. Functional Requirements

Requirement ID	Requirement	Primary User
FR-01	The system shall allow authorized users to search for books by title, author, or category.	Student, Librarian
FR-02	The system shall allow authorized librarians to register new books.	Librarian
FR-03	The system shall record book borrowing transactions.	Librarian
FR-04	The system shall record book return transactions.	Librarian
FR-05	The system shall identify books whose return dates have passed.	Librarian
FR-06	The system shall allow authorized staff to register and update student membership records.	Librarian
FR-07	The system shall allow authorized staff to update book information.	Librarian
FR-08	The system shall maintain a history of borrowing and return transactions.	Librarian, Library Administrator
FR-09	The system shall display book availability.	Student, Librarian
FR-10	The system shall generate reports about borrowing transactions and overdue books.	Library Administrator
FR-11	The system shall allow authorized users to log in to the system.	Authorized Users
FR-12	The system shall allow authorized staff to retrieve student borrowing records.	Librarian

3. Requirement Clarifications

The following points require confirmation from the project team:

* Whether students will have individual accounts.
* Whether students can renew borrowed books.
* Whether the system will calculate overdue fines.
* Whether students can reserve books that are unavailable.
* Which reports will be required by library administrators.
* Which user roles can create, update, or delete records.

4. Review Status

Status: Preliminary.

The project team must review these requirements and confirm that they match the agreed project scope.

5. Conclusion

These functional requirements provide an initial description of the operations expected from the University Library Management System. They will support further requirements analysis and the preparation of detailed specifications in Assignment 2.
